## Organization

All frontend-related documentation is organized here to keep the root directory clean per reference.md standards.

**Structure:**
- Root: Only `README.md` and `spec.md` (per reference.md)
- `/docs/`: Product and user-facing documentation
- `/backend/docs/`: Backend engineering documentation
- `/frontend/docs/`: Frontend engineering documentation (this directory)
- `/deploy/docs/`: Deployment documentation (when needed)

This organization ensures:
- ✅ Single, clean README.md in root
- ✅ Predictable discovery of documentation
- ✅ Separation of engineering docs from product docs
- ✅ Easy navigation by component

For product/user documentation, see the root `/docs/` directory.
